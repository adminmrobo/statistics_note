# 우연의 과학통계학

통계학의 기초에서 확률, 확률분포, 추정, 가설검정까지 다루는 연구실 해설 시리즈입니다. 예제를 손으로 풀어 보고, 계산기로 숫자를 바꿔 볼 수 있습니다.

- 전체 목차: https://adminmrobo.github.io/statistics_note/

| 장 | 내용 | 페이지 |
|---|---|---|
| [1장 통계학의 기초](ch01/) | 모수와 통계량, 자료의 종류, 중심·흩어짐·모양·관계, 데이터 시각화 | 1편 |
| [2장 확률의 연산과 베이즈 정리](ch02/) | 확률의 정의, 조건부확률, 독립·배반사건, 베이즈 정리, 확률변수와 공분산·상관계수 | 3편 |
| [3장 이산확률분포](ch03/) | 베르누이·이항·기하·음이항·포아송·초기하·다항분포, PMF와 PDF | 2편 |
| [4장 통계적 추정](ch04/) | 점추정과 구간추정, t·카이제곱·F분포, 표본분포, 자유도, 신뢰구간 사례, 모의고사 | 11편 |
| [5장 통계적 가설검정](ch05/) | 가설검정의 논리, 단일·두 집단 검정, 분산분석, 모의고사 | 6편 |

## 폴더 구성

- `chXX/` — 장별 해설 페이지(HTML 한 파일씩), `assets/`(공유 미리보기·목차 그림, 캐릭터 그림), `data/`(예제 데이터), `pdfs/`(모의고사 인쇄본)
- `production/KG_00_registry.json` — 시리즈 지식 색인 등록부

모든 페이지는 외부 라이브러리 없이 한 파일로 동작합니다. 예제의 숫자는 설명용 예시값이며, 투자·의료 판단을 권하는 자료가 아닙니다.
